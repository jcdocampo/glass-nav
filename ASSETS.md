# Asset credits

## Philippine scenery

The gallery uses original AI-generated illustrations inspired by Palawan,
the Cordillera rice terraces, and Albay. They are illustrative landscapes,
not documentary photographs of exact viewpoints. Each image is a 1200 by
800 WebP with source metadata omitted.

## Cover and recorded demonstration

`assets/thumbnail.webp` is the project cover supplied by the maintainer,
converted from PNG to WebP. It shows the four navigation icons and a
refractive lens activated by an index finger.

`assets/demo.mp4` records the current GlassNav example, including the
Philippine scenery, the 4:3 scrollable scene, and the appearance controls.
`assets/demo-preview.gif` is a smaller animated preview of the same recording.

The supplied cover, generated scenery, and recorded demo media are shared
under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
Credit jcdocampo and link to this project when sharing adapted media.
Source code is covered separately by the MIT license in `LICENSE`.
